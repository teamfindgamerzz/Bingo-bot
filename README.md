
# Bingo Bot

**Bingo** is a Discord moderation and utility bot.

## Features

- Moderation commands
- Welcome and leave messages
- AFK system
- Poll system
- Server information
- Channel lock and unlock
- Support and invite commands

## Commands

- `/help`
- `/ban`
- `/kick`
- `/timeout`
- `/warn`
- `/clear`
- `/afk`
- `/poll`
- `/lock`
- `/unlock`
- `/serverinfo`
- `/support`
- `/invite`

## Technology

- Node.js
- Discord.js v14
- JavaScript
